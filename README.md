# phase-rs-zh

把 [phase.rs](https://phase-rs.dev) 网页版的卡图换成
[大学院废墟](https://mtgch.com)（mtgch.com）的简体中文图。

一个书签，不用装任何东西。

## 安装（30 秒）

### 👉 [点这里打开安装页](https://haowen1993.github.io/phase-rs-zh/)

1. 打开上面那个页面
2. 把页面里的红色「**中文卡图**」按钮**拖到书签栏**
   （拖不动就右键它 → 添加到书签。没有书签栏按 <kbd>⌥⌘B</kbd> 或 <kbd>Ctrl+Shift+B</kbd>）
3. 打开 <https://phase-rs.dev>，**点一下书签栏里的「中文卡图」**

> ⚠️ **每次刷新或重新打开页面后，都要再点一下书签。**（页面内跳转不用点）
> 这就是「零安装」的代价。

## 它做什么

| 这张卡的情况 | 你会看到 |
| --- | --- |
| 大学院废墟有简体中文图 | 中文卡图 |
| 没有中文图 | 大学院废墟的英文图 |
| 连英文图都没有 | 原来的英文图（兜底，几乎不会发生） |

正面、背面（双面牌）、大小尺寸、衍生物都覆盖。全程自动，你不需要做任何判断。

## 常见问题

**点了没反应？** 多半是忘了点书签，或刷新之后没再点。
**有些卡还是英文？** 正常——大学院废墟没有那些印刷的中文图，自动用了它的英文图。
**想换浏览器或换电脑？** 新建一个书签，把地址换成 `dist/phase-rs-zh.bookmarklet.txt`
里的那一行即可，任何浏览器、任何系统都行。
**想发给别人？** 把上面那个安装页网址发过去就行。
**卡图变成文字占位卡？** 不正常，请告诉我卡名。
